Marketing sites are brand assets, not open-source software. There is no
legitimate use case for someone else to copy this site's content
verbatim into a different product — anyone doing so would necessarily
be impersonating the Sanctum brand, which the absence of a license
already prohibits under default copyright.

configuration, build pipeline) for your own marketing site, ask. The
underlying code patterns aren't precious; the brand voice is.
